# pyproj

**Статус проекта: Active**

pyproj — небольшой генератор Python-проектов для командной строки, использующий uv для управления окружением и зависимостями.

Он создаёт директорию проекта, копирует выбранный шаблон, заменяет `{{PROJECT_NAME}}` и запускает `uv sync`, который создаёт виртуальное окружение и устанавливает зависимости шаблона.

> **Статус:** Alpha. Проект всё ещё находится в разработке, а создание репозиториев GitHub пока не реализовано.

## Текущие возможности

• Создание проекта в директории Python-проектов по умолчанию

• Копирование файлов из выбранного шаблона проекта

• Использование basic по умолчанию

• Поддержка шаблонов basic, telegram и kivymd

• Замена `{{PROJECT_NAME}}` в поддерживаемых текстовых файлах

• Управление окружением и зависимостями через uv

• Обработка коротких и длинных флагов командной строки

• Обнаружение неизвестных и конфликтующих флагов

• Предотвращение перезаписи существующей директории проекта

• Цветные сообщения о прогрессе, успехе, предупреждениях и ошибках

## Установка

После установки uv синхронизируйте репозиторий:

```bash
uv sync
```

## Использование

```bash
uv run python main.py my_project
uv run python main.py my_bot --telegram
uv run python main.py my_app --kivy
```

Короткие версии:

```bash
uv run python main.py my_bot -tg
uv run python main.py my_app -kv
```

## Доступные флаги

|Короткий|Длинный     |Назначение                                                     |
|--------|------------|---------------------------------------------------------------|
|`-tg`   |`--telegram`|Использовать шаблон Telegram-бота                              |
|`-kv`   |`--kivy`    |Использовать шаблон KivyMD                                     |
|`-gh`   |`--github`  |Создать репозиторий GitHub *(запланировано)*                   |
|`-pb`   |`--public`  |Сделать репозиторий GitHub публичным *(запланировано)*         |
|`-pv`   |`--private` |Сделать репозиторий GitHub приватным *(запланировано)*         |

## Как работает генерация

```text
create_directory()
        ↓
copy_template()
        ↓
replace_placeholders()
        ↓
uv sync
```

Каждый шаблон содержит собственный `pyproject.toml`. После копирования шаблона и замены placeholders команда `uv sync` создаёт `.venv` и устанавливает объявленные зависимости.
