pyproj

pyproj — это небольшой генератор проектов для командной строки, написанный на Python.

Он создаёт новую директорию проекта, копирует выбранный шаблон, заменяет шаблонные заполнители, такие как {{PROJECT_NAME}}, создаёт виртуальное окружение и устанавливает зависимости шаблона, если присутствует файл requirements.txt.

> **Статус:** Alpha. Проект всё ещё находится в разработке, а создание репозиториев GitHub пока не реализовано.

Текущие возможности

• Создание проекта в директории Python-проектов по умолчанию
• Копирование файлов из выбранного шаблона проекта
• Использование базового шаблона по умолчанию
• Поддержка шаблонов basic, telegram и kivymd
• Замена {{PROJECT_NAME}} в поддерживаемых текстовых файлах
• Создание виртуального окружения .venv
• Установка зависимостей из requirements.txt
• Обработка коротких и длинных флагов командной строки
• Обнаружение неизвестных флагов
• Предотвращение конфликтов между флагами шаблонов
• Предотвращение перезаписи уже существующей директории проекта
• Отображение цветных сообщений о прогрессе, успехе, предупреждениях и ошибках
• Скрытие ненужных трассировок для ожидаемых пользовательских ошибок

Использование

Запустите генератор, указав название проекта:

```bash
python main.py my_project
```

Проект будет создан с использованием базового шаблона.

Чтобы использовать другой шаблон:

```bash
python main.py my_bot --telegram
python main.py my_app --kivy
```

Короткие версии:

```bash
python main.py my_bot -tg
python main.py my_app -kv
```

Доступные флаги

|Короткий|Длинный     |Назначение                                                     |
|--------|------------|---------------------------------------------------------------|
|`-tg`   |`--telegram`|Использовать шаблон Telegram-бота                              |
|`-kv`   |`--kivy`    |Использовать шаблон KivyMD                                     |
|`-gh`   |`--github`  |Создать репозиторий GitHub *(запланировано)*                   |
|`-pb`   |`--public`  |Сделать репозиторий GitHub публичным *(запланировано)*         |
|`-pv`   |`--private` |Сделать репозиторий GitHub приватным *(запланировано)*         |

Шаблоны Telegram и KivyMD уже доступны. Создание репозиториев GitHub и флаги видимости всё ещё находятся в разработке.

Структура проекта

```text
pyproj/
├── main.py
├── core/
│   ├── parser.py
│   ├── project.py
│   └── logger.py
└── templates/
    ├── basic/
    ├── telegram/
    └── kivymd/
```

Как работает генерация

```text
create_directory()
        ↓
copy_template()
        ↓
replace_placeholders()
        ↓
create_venv()
        ↓
install_dependencies()
```

Генератор заменяет {{PROJECT_NAME}} в поддерживаемых типах файлов:

• .py
• .txt
• .md
• .kv

Если выбранный шаблон содержит файл requirements.txt, его зависимости устанавливаются внутри только что созданного виртуального окружения.

Требования

• Python 3.10 или новее
• colorama 0.4.6 или новее
